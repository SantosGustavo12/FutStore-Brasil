# FutStore-Brasil

Sobre o Projeto
Projeto acadêmico desenvolvido para a disciplina de Análise de Dados com Python, com foco na aplicação do processo completo de ETL (Extract, Transform, Load), análise exploratória de dados e criação de um dashboard executivo com KPIs de negócio.
O dataset utilizado simula as vendas de uma loja fictícia de artigos esportivos de futebol — a FutStore Brasil — cobrindo o período de Janeiro a Junho de 2024.
